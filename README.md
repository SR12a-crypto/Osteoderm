**Osteoderm**

**An Integrated Skin Imaging and Screening Prototype**

Osteoderm is a hardware and software prototype exploring the integration of skin imaging, scanning technology, and digital data management to support preliminary skin assessment and research.

The project combines a physical device concept designed using ZooCAD with a web application built using React and Node.js, backed by a PostgreSQL database.

**Technology Stack**

- React — Frontend user interface
- Node.js — Backend runtime and application logic
- PostgreSQL — Structured data storage
- ZooCAD — Hardware prototype and CAD enclosure design

**Project Vision**

Osteoderm aims to explore how integrated imaging hardware and software could improve the consistency of image capture, organization of screening records, and future research into AI-assisted skin analysis.

The project is currently a prototype. Its hardware configuration, scanning capabilities, and diagnostic performance must be validated before any clinical use.
